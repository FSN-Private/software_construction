# Darktable native rendering corpus

This corpus uses one CC0 Canon EOS 1000D CR2 original and four project-authored darktable XMP states: the current state and three historical revisions. The original is downloaded only by the corpus setup from raw.pixls.us and is accepted only when its published SHA-256 is `08b0843a7968315b68bd3c71a96c952ebf275d5b5eba4b6094ae8b103522584c`.

The revisions use exposure-v5 manual mode with neutral black correction and vary only exposure EV. `reference/*.pfm` contains the owner-approved portable candidate's 512px thumbnail and 2048px preview references, preserving aspect ratio. PFM excludes JPEG's run-specific metadata; `run-native.sh` rejects malformed/non-finite pixels and compares every reference byte while retaining JPEG provenance. The [reference approval and exact hashes](../../../docs/features/011-backup-disaster-recovery/reviews/portable-renderer-reference-proposal.md) replace malformed legacy fixtures and two NaN references; previous bytes remain in Git history. Runtime qualification still requires the exact registry digest, current security evidence, trusted-Linux corpus and deployed acceptance.
