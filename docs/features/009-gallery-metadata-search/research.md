# Gallery Design Research

- **Projection store**: Use indexed PostgreSQL tables already operated by the platform. A separate search cluster adds deployment and recovery burden at 100,000 assets; validate with T013 before revisiting.
- **Pagination**: Use keyset tuples and asset-ID tie-breakers, with generation-bound cursors. Offset paging can repeat/skip after insertion and degrades on deep pages.
- **Working changes**: Feature 006 scopes rows to client and branch, while feature 007 currently lists committed projection only. Reserve a web client and add an explicit branch overlay to namespace reads; retain device-local working rows and report conflicts. A per-device fanout would make partial delivery and cleanup harder.
- **XMP**: Parse with secure `XmlReader` settings and patch only allowlisted RDF/darktable fields in an XML DOM. Preserve all unknown elements/attributes and validate with a darktable round trip; byte formatting may change, so compare semantics as well as the untouched original binary.
- **Embedded metadata**: Feature 005 validates JPEG, PNG, TIFF, and DNG but does not extract searchable EXIF. Selected `MetadataExtractor` 2.9.3 from [NuGet](https://www.nuget.org/packages/MetadataExtractor), built for net8.0 and compatible with the API's net10.0 target. The [upstream project](https://github.com/drewnoakes/metadata-extractor-dotnet) documents EXIF/IPTC/XMP and DNG, JPEG, PNG, and TIFF support. Apache-2.0 license; the sole new transitive package is `XmpCore` 6.1.10.1, which [upstream](https://github.com/drewnoakes/xmp-core-dotnet) identifies as BSD licensed. Both exact package hashes are recorded in `apps/api/packages.lock.json`; no other package changed. On 2026-09-25, `dotnet restore apps/api/Platform.Api.csproj --force-evaluate`, `dotnet build apps/api/Platform.Api.csproj --no-restore --nologo`, and `dotnet list apps/api/Platform.Api.csproj package --vulnerable --include-transitive` passed with no reported vulnerable packages. T004 verifies the accepted fixture corpus; remove this package if those tests show it cannot meet the supported-format contract.
- **Privacy**: Apply location visibility in the server query before both matches and counts. Client-only hiding would leak coordinates through search outcomes and API payloads.
- **Browser checks**: Pin test-only `@playwright/test` 1.63.0 (Apache-2.0, Microsoft-maintained) in `apps/web/package-lock.json` to run the UI against Chrome for Testing, Microsoft Edge, and Playwright Firefox. Installation used `--ignore-scripts`; the browser binaries are fetched separately from Playwright's official distribution. It adds `playwright` and `playwright-core` only to the web development dependency graph and does not enter the production Vite bundle. `npm audit --audit-level=moderate` reported zero vulnerabilities on 2026-09-25. CI downloads browsers into its disposable runner and executes the same suite.
