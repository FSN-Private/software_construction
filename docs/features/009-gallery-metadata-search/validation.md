Cached thumbnail timing is measured as each lazy-loaded card is brought into view; all 40 images must decode successfully, and at least one S3 response must be HTTP 200. The fixture is local and does not substitute for the separate hosted Windows Cloud Files/darktable compatibility gate or a production deployment smoke test.
